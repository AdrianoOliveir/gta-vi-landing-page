# 🎮 GTA V  - Landing Page

Uma landing page inspirada no universo de **Grand Theft Auto V**, desenvolvida como projeto de estudo e prática de desenvolvimento web.

> ⚠️ **Projeto não oficial.** Esta página é apenas uma representação visual criada para fins educacionais.

## 📌 Sobre o projeto

Este projeto consiste em uma página de apresentação inspirada em **GTA VI**, criada para colocar em prática conhecimentos de **HTML, CSS e JavaScript**.

A proposta é desenvolver uma interface simples, moderna e visualmente inspirada no jogo, explorando conceitos fundamentais do desenvolvimento Front-End.

## 🚀 Tecnologias utilizadas

- **HTML5** — Estrutura e organização da página
- **CSS3** — Estilização, layout, responsividade e efeitos visuais
- **JavaScript** — Interações e comportamentos da página

## 🎯 Objetivo

O principal objetivo deste projeto é **praticar e consolidar conhecimentos de desenvolvimento web**, aplicando na prática conceitos estudados em:

- Estruturação de páginas com HTML
- Estilização com CSS
- Layout e responsividade
- Manipulação do DOM
- JavaScript
- Interações com o usuário
- Organização de um projeto Front-End
- Versionamento com Git e GitHub

## 🖥️ Projeto

A página apresenta uma representação visual inspirada em **Grand Theft Auto VI**, utilizando elementos visuais, seções e interações desenvolvidas exclusivamente para fins de estudo.

O projeto não possui vínculo oficial com a Rockstar Games ou com a franquia Grand Theft Auto.

## 📚 Contexto

Este projeto faz parte dos meus estudos em desenvolvimento web e representa uma aplicação prática dos conhecimentos adquiridos durante minha jornada de aprendizado em **HTML, CSS e JavaScript**.

A ideia é evoluir o projeto gradualmente conforme novos conceitos forem aprendidos.
